# Papers

Free full-text copies of Ben Chester Cheong's publications, served at `https://benchestercheong.com/papers/<file name>`.

## Adding a paper

1. Name the PDF after the entry's Ref (the `id` in `index.html`, also used in the links spreadsheet), for example `framework-jel-2025.pdf`. Use lowercase letters, numbers and hyphens only.
2. Upload it to this folder: **Add file → Upload files**, then **Commit changes** to `main`. The browser upload limit is 25 MB per file.
3. Link it from the publication entry as its full-text copy.

## Only upload versions you may share

This repository is public, so anyone can download what is here.

- Open-access articles (for example Frontiers, Springer Discover, SN Social Sciences): the published PDF is usually fine.
- Subscription journals (Sweet & Maxwell, Oxford, Cambridge, Taylor & Francis, SAGE): usually only the author's accepted manuscript, sometimes after an embargo. Check the journal's policy in Sherpa Romeo (Open Policy Finder) first.
- Newspaper op-eds: don't upload the newspaper's page or PDF. Link the NUS News copy instead.
